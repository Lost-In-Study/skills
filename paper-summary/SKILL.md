# Paper Summary

## 触发条件

以下情况**必须**主动调用此 skill，不要用 Agent 工具直接处理：

- 用户发送 arXiv 链接（`arxiv.org/abs/` 或 `arxiv.org/html/`）
- 用户发送任何论文 / 博客链接并要求解读、总结、笔记
- 用户上传或粘贴论文 PDF，要求解读（如 `@xxx.pdf 中文解读`）
- 用户说"解读一下"、"中文解读"、"帮我看看这篇"、"整理成笔记"、"论文笔记"
- 用户说"写入文档"且当前对话上下文是论文解读

不触发的情况：用户只是问某个概念的含义（不涉及具体论文链接或文件）。

---

## 这个 Skill 做什么

获取论文或博客文章，输出符合 Obsidian 笔记库规范的中文解读，并在用户说"写入文档"时自动写入对应子目录。

---

## 工作流

### Step 1 · 获取原文

优先顺序：

1. **arXiv HTML 版**（`https://arxiv.org/html/XXXX.XXXXX`）——无需 PDF，直接可读
2. 用户提供的链接（博客 / 会议页面 / GitHub）
3. 用户粘贴的摘要 / 全文

> **注意**：微信公众号文章无法访问，遇到时告知用户并请其粘贴全文或提供可访问链接。

---

### Step 2 · 确定写入位置

根据内容主题路由到对应子目录：

| 主题 | 目录 |
|------|------|
| 召回模型（DSSM、TDM、SDM 等） | `算法知识/00召回/` |
| 粗排（ESMM、ESDM 等） | `算法知识/01粗排/` |
| 精排（SIM、ETA、CrossAttention、MoE 等） | `算法知识/02精排/` |
| 重排（DPP、MMR、SSD 等） | `算法知识/03重排/` |
| 损失函数（BPR、Focal、LambdaRank 等） | `算法知识/04损失函数/` |
| 多模态（CLIP、BEiT3、word2vec 等） | `算法知识/05多模态/` |
| 大模型、Agent、强化学习、扩散模型 | `算法知识/06大模型/` |
| 训练技巧（BN、Dropout 等） | `算法知识/07训练技巧/` |
| 计算广告（拍卖、出价、RL 广告） | `算法知识/计算广告/` |

不确定时询问用户，或默认放 `算法知识/06大模型/`。

---

### Step 3 · 撰写解读

#### 论文笔记模板

```markdown
#{标签1} #{标签2} #论文笔记

> 原文：Author Name et al., "Paper Title", Venue Year
> https://arxiv.org/abs/XXXX.XXXXX
> 机构：Institution A + Institution B
> 代码：https://github.com/...（如有）

## 问题：{核心问题}

{背景与动机}

---

## 解法：{方案名称}

{核心方法、关键公式、架构图文字描述}

---

## 实验结果

{主要 benchmark 表格 + 核心结论}

---

## 概念辨析（如有 Q&A 讨论则补充）

### {概念}

{解释}

---

## Takeaway

- {要点 1}
- {要点 2}
- {要点 3}
```

#### 博客 / 综述模板

```markdown
#{标签1} #{标签2} #综述

> 原文：Author Name, "Title", Month YYYY
> https://...
> 机构：{作者所在机构}（如已知）

## 一句话总结

{核心观点}

---

## {章节标题}

{内容}

---

## Takeaway / 定位与延伸

{要点列表}
```

#### 写作规则

- **语言**：中文正文，英文专有名词保留原文（如 GRPO、Transformer）
- **来源归属**：blockquote 中必须包含作者、标题、年份、URL、**机构**，有代码仓库则加 `代码：` 行
- **公式**：使用 LaTeX（`$$...$$` 块级，`$...$` 行内）
- **标签**：放在笔记第一行，从下方列表选取
- **长度**：覆盖核心思想、方法、实验即可，不逐段翻译
- **Q&A 整理**：用户追问的内容优先**就地扩写对应章节**——在相关段落里直接补充解释，让正文更完整；不要新增独立的"概念辨析"小节。只有当讨论的概念明显跨越多个章节、或属于与论文无直接对应的背景知识时，才用 `### 概念名` 三级标题放入"概念辨析"小节
- **文件名**：用论文/博客的英文简称（如 `CalibAdv.md`、`ReAct.md`）

#### 常用标签

```
#论文笔记 #综述 #大模型 #Agent #强化学习 #扩散模型
#召回 #粗排 #精排 #重排 #损失函数 #多模态
#训练技巧 #计算广告 #推荐系统
```

---

### Step 4 · 写入文档

用户说"**写入文档**"时：

1. 确认目标路径（Step 2 路由结果）
2. 用 Write 工具写入 `{目录}/{文件名}.md`
3. 如果文件已存在，用 Edit 追加新内容（不覆盖已有内容）
4. 告知用户写入路径

---

## 示例对话

```
用户：https://arxiv.org/abs/2210.03629 中文解读下这篇论文
→ 读取 HTML 版 → 输出中文解读

用户：写入文档
→ 识别为 Agent/大模型论文 → 写入 算法知识/06大模型/ReAct.md

用户：react和cot什么区别
→ 补充解释

用户：把我们的讨论也整理进文档
→ 判断每个概念归属哪个章节 → 优先用 Edit 就地扩写对应段落
→ 只有跨章节或背景性概念才放入"概念辨析"小节
```
